# Pitch Playground

A small browser-based ear-training tool for practicing pitch, intonation, and frequency recognition using the Web Audio API.

Live demo: [https://p.jeltz.org/](https://p.jeltz.org/)

## Table of Contents

- [Features](#features)
- [Usage](#usage)
- [Files](#files)
- [Technologies](#technologies)
- [License](#license)

## Features

- Play reference notes with adjustable A4 tuning
- Practice identifying flat vs. sharp pitch
- Pick the correctly tuned target from multiple candidates
- Adjustable waveform, duration, interval, range, and candidate count
- Basic streak and error statistics
- No dependencies or build step

## Usage

Open `index.html` in a modern browser. Many browsers support opening `index.html` from a file:// path, removing the web server requirement.

## Files

- `index.html` — interface
- `index.css` — styles
- `index.js` — audio, exercises, and application logic

## Technologies

Vanilla HTML, CSS, JavaScript, and the Web Audio API.
